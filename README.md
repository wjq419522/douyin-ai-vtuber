# 佳垚 · 抖音 AI 虚拟主播（原型）

一个**原创**的东方古典虚拟主播：读取直播弹幕 → 大模型回答 → 语音播报 + 口型 + 动作，会作诗、作画、唱原创小调、跳舞、弹古筝/琵琶/古琴/吉他/钢琴，吹笛子/箫，拉二胡；会像成熟主播一样暖场、点名、谢礼物；会记住观众、根据直播数据自己调整节目，新学到的知识经你批准后才使用。

> 形象定位：自然、端庄、大方的东方古典女子。**原创设计，不取材、不模仿任何真实人物的长相或声音**（这是法律红线，也是抖音审核重点）。

---

## 1. 快速运行（5 分钟）

```bash
pip install -r requirements.txt
cp .env.example .env          # 不填任何 Key 也能跑（离线演示大脑 + 浏览器 TTS + 程序化水墨画）
python -m server.main
```

- 控制台（操作员用）：http://127.0.0.1:8765/console
- 直播画面：http://127.0.0.1:8765/overlay （竖屏 1080×1920；加 `?green=1` 变绿幕）

在控制台点“你好呀 / 给我作首诗 / 画一幅江南烟雨 / 弹古筝 / 加个微信呗”等按钮就能看到效果。默认是**人工审核**模式：每条回复要你点“批准播出”。

**接抖音直播：** 打开「抖音直播伴侣」（PC）→ 添加素材“浏览器/网页” → 填 overlay 地址，宽 1080 高 1920。也可用 OBS 采集后通过直播伴侣的“OBS 推流”或推流码开播（推流码权限以账号等级为准）。

---

### 写实真人形象

直播画面地址改成 `http://127.0.0.1:8765/overlay?avatar=video`，就会用 `web/avatar/` 里的写实视频片段代替动漫形象：按弹幕切换待机、说话、挥手、跳舞、弹琴、作画等片段；配置了口型同步服务（`LIPSYNC_URL`）时，说话会播放按本句语音实时生成的口型视频。
人物怎么做（原创写实面孔、动作片段、口型、音色）和合规要求见 [docs/realistic-avatar.md](docs/realistic-avatar.md)。

## 2. 架构

```
 抖音开放平台·直播互动 ──webhook──┐
 （官方弹幕/礼物/点赞推送）          │
 操作员控制台 / 测试注入 ───────────┤
                                     ▼
                     ┌──────── 中控 server/main.py ────────┐
                     │ 限流去重 → 输入过滤(safety)          │
                     │ → 观众记忆(memory) + 已审知识检索    │
                     │ → 大脑(brain: 大模型 + 人设 + 意图)  │
                     │ → 输出过滤 + 广告法检查              │
                     │ → 人工审核/自动播出                  │
                     │ 主播技巧(host): 暖场/点名/节目单     │
                     │ 自主学习: 节目效果统计 + 候选知识    │
                     └───────┬──────────────────────────────┘
                             │ WebSocket
                             ▼
       overlay.html：形象(口型/眨眼/动作/跳舞) · 字幕 · 弹幕
                     作诗竖排 · 作画画布 · Web Audio 乐器/哼唱
                     常驻「AI生成 · 虚拟主播」标识
                             │
                    抖音直播伴侣 / OBS ──推流──▶ 抖音
```

| 模块 | 文件 | 原型里的实现 | 正式上线建议替换为 |
|---|---|---|---|
| 形象 | `web/overlay.html` | 程序化 SVG 原创形象，口型/眨眼/挥手/点头/害羞/跳舞/弹琴/执笔/持扇 | 委托画师做 **Live2D** 模型 + VTube Studio（性价比最高）；或 UE5 MetaHuman 原创 3D（需高配显卡） |
| 大脑 | `server/brain.py` | OpenAI 兼容接口，内置人设与 JSON 动作协议；无 Key 时离线演示 | 国内已备案大模型：DeepSeek / 通义千问 / 豆包 / 智谱 |
| 语音 | `server/main.py` `tts()` | edge-tts，失败回落浏览器 TTS | CosyVoice / GPT-SoVITS 用**你自己拥有授权**的音色训练 |
| 唱歌 | overlay `voice()` | 共振峰合成“哼唱” + 古筝伴奏 + 卡拉OK字幕 | DiffSinger / ACE Studio 等歌声合成，只唱原创或已获授权的歌 |
| 乐器 | overlay `INST` | Karplus-Strong 拨弦（古筝/琵琶/古琴/吉他）、钢琴泛音、笛/箫/二胡带揉弦 | 采样音源（SoundFont）或 MIDI → 专业音源 |
| 作画 | `brain.generate_image` | 未配置时程序化逐层晕染水墨山水，画上自带“AI生成”角标 | 通义万相 / 可图 / SDXL，经内容审核后展示 |
| 作诗 | 大模型 | 竖排逐字书写 | 同左 |
| 弹幕 | `server/douyin.py` | 抖音开放平台推送 webhook（含验签）+ 通用 `/api/danmaku` | 同左 |
| 主播技巧 | `server/host.py` | 欢迎新人/认出老粉/谢礼物/点名/冷场节目/节目单/飞花令/讲典故/带货讲解 | 按运营复盘持续调参 |
| 自主学习 | `server/memory.py` | SQLite：观众记忆、节目效果多臂老虎机、候选知识审核 | 知识量大了换向量库（bge-m3 + Chroma/FAISS） |
| 安全 | `server/safety.py` | 本地词表（防谐音插空）、限流去重、输出二次检查 | 叠加云内容审核 API（阿里云/腾讯云/数美） |

## 3. 向头部主播学到的“通用”技巧（已实现）

只学方法，不复制任何具体主播的人设、口头禅、形象或声音。

1. **进场欢迎**：新观众第一次发言自动欢迎并引导玩法；隔 6 小时以上回来的老粉会被“认出”并提起上次聊的话题。
2. **谢礼物但不诱导**：感谢 + 提醒理性消费、未成年人勿打赏；输出过滤会拦截“刷礼物就…”“榜一”等诱导话术。
3. **点名互动**：每 3 分钟从最近发言的观众里点一位提问，拉高互动率。
4. **冷场暖场**：25 秒无弹幕自动上节目（作诗/唱/跳/弹/画/讲典故/飞花令）。
5. **节目单节奏**：开场 → 才艺 → 互动，可在 `rundown.json` 自定义（参考 `rundown.example.json`）。
6. **带货讲解（可选）**：`products.json` 配商品后控制台出现按钮；强制人工审核，并检查广告法绝对化用语。**注意：AI 数字人带货需满足抖音电商的资质与数字人带货规则，请先确认账号权限。**
7. **PK / 连麦**：涉及与其他真人主播实时互动，系统**不自动发起**，控制台给操作员提示话术。

## 4. 自主学习（已实现，带护栏）

- **记住观众**：昵称、来访次数、聊过的话题、礼物次数，存 `runtime_memory.db`，重启不丢。
- **节目自优化**：每个主动节目播出后统计 60 秒内的弹幕、点赞、进场作为“得分”，用 Thompson Sampling 挑下一次冷场节目——越受欢迎越常上，同时保留探索。控制台可看到每个节目的受欢迎度。
- **知识学习**：你在审核时改过的回答、你手动“教给她”的问答，进入“待批准知识”；**批准后**才会在相似问题里被检索出来参考。控制台还会列出 24 小时高频问题，方便你补充标准答案。
- 为什么不让她“完全自己学”：直播间观众可以故意教坏机器人，平台也要求生成内容可控，所以所有新知识都过一道人工审核。

## 5. 合规清单（按抖音及国内法规）

上线前请逐条确认，具体以抖音最新规则为准：

1. **显著标识**：画面左上角常驻“AI生成 · 虚拟主播”，底部常驻提示；画作上直接打“AI生成”角标。依据《人工智能生成合成内容标识办法》（2025-09-01 施行）、《互联网信息服务深度合成管理规定》、抖音《关于人工智能生成内容的平台规范暨行业倡议》。
2. **虚拟人注册 + 真人实名负责**：在抖音完成虚拟人形象注册，开播账号由实名认证的真人负责。
3. **不得无人值守**：抖音不允许纯 AI 无人直播。本系统设计为**真人操作员在场心跳**：控制台关闭或 2 分钟无响应，机器人自动停止回复并显示“主播暂离”；还有“一键急停”。
4. **形象/声音原创且有授权**：不使用任何真人肖像、明星脸、他人声音；Live2D 模型和音色要有商用授权书。
5. **内容安全**：不低俗、不擦边、不引流私下交易、不诱导打赏、不承诺收益；被问“是不是真人”必须如实说是 AI。
6. **版权**：只唱原创小调或已获授权的歌，背景音乐用正版曲库。
7. **未成年人保护**：谢礼物时提醒理性消费；不针对未成年人营销。
8. **弹幕获取**：只用抖音开放平台官方“直播互动”推送。**不要使用逆向抓取直播间 WebSocket 的开源工具**，违反用户协议，可能封号并有法律风险。
9. **大模型**：面向国内公众服务应使用已完成生成式 AI 备案的大模型。
10. **粉丝群互动**：抖音粉丝群目前没有公开的机器人接口，建议由操作员把群里的问题粘贴到控制台“手动注入”，或等官方开放能力后接入 `/api/danmaku`。

## 6. 需要你自己准备的东西

| 项目 | 说明 |
|---|---|
| 抖音账号 | 实名认证，开通直播权限；完成虚拟人形象注册 |
| 抖音开放平台开发者 | 企业或个体工商户主体，申请“直播互动/直播小玩法”能力，拿 app_id/secret，配置公网 HTTPS 回调 |
| 大模型 API Key | DeepSeek / 通义千问 / 豆包等，填到 `.env` |
| 形象 | 委托画师做原创 Live2D 模型（建议按本文开头的形象定位写设定稿），签商用授权 |
| 音色 | 购买商用 TTS 音色，或找配音员签授权后训练 |
| 电脑 | Windows，建议 16G 内存 + 独显（Live2D 够用；MetaHuman 需 RTX 3070 以上） |
| 真人操作员 | 开播全程在控制台值守 |
